# Let's Meet

Encuentra una hora que os vaya bien a todos, sin cuentas ni registros.

**Abrir la app:** https://sneal4you.github.io/letsmeet/

## Cómo se usa

1. Escribe tu nombre, elige un color y crea la quedada.
2. Pasa el enlace de invitación al grupo.
3. Cada persona marca sus horas libres en la rejilla y pulsa **Enviar**.
4. Las franjas en las que coincidís todos brillan.

Funciona en iPhone y Android desde el navegador.

## Privacidad

- No hay cuentas ni base de datos propia.
- Los horarios viajan cifrados. La clave solo está en el enlace de la quedada.
- Cada móvil guarda su propia copia.
- Quien tenga el enlace de invitación puede ver y marcar horas: compártelo solo con tu grupo.
- No compartas tu enlace personal: permite escribir en tu nombre.

## Desarrollo

Sin dependencias ni compilación. Requiere Node 22 o superior.

```
npm test
node scripts/serve.mjs 8080
```
